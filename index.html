ENGINE FEATURES

Everything you actually use from a modern wallpaper engine, without dragging Chromium or mpv into RAM.

AUTO-PAUSE

Automatically halts video decoding on fullscreen or maximized apps and when running on laptop battery — dropping CPU/GPU usage to ~0%.

MULTI-MONITOR

Duplicate independently per display, span across your virtual desktop, or run on primary only. Handles display hot-plugging live.

DROP ANY VIDEO

Drag and drop any .mp4, .m4v, .mov, or .wmv file or folder straight onto the pixel-art Control Panel, with Fill, Fit, or Stretch scaling.

WARP TRANSITIONS

Extracts bright stars from the departing frame and streaks them across deep space while smoothly swapping to the next loop.

PLAYBACK SPEED

Run calm 0.5x ambient orbits or crisp 2x time-lapses on the fly from the tray menu or Control Panel.

WINDOWS 11 24H2 READY

Properly slots a per-monitor DPI-aware layered child window between SHELLDLL_DefView and WorkerW on modern Windows 11.

LIVE BROWSER STUDIOS

Customize tilt, zoom, pixel grid size, and export seamless 1080p, 1440p, or 4K 60fps MP4 loops directly in Chrome or Edge via WebCodecs.

BUILD FROM SOURCE

No Visual Studio needed — compiles in under 2 seconds using the C# compiler already inside Windows.

git clone https://github.com/Ism2498/event-horizon-wallpaper.git
cd event-horizon-wallpaper
powershell -ExecutionPolicy Bypass -File .\video-wallpaper.ps1 -BuildOnly
.\VideoWallpaper.exe "path\to\your-loop.mp4"
